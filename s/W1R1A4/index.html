손으로 싸는 시늉을 하며 부탁해요.

Is this a gift? Should I wrap it?

선물이에요? 포장해 드릴까요?

Yes, please—wrap it like this!

네, 이렇게 싸 주세요!

오늘의 표현wrap it like this이렇게 싸 주세요(보여 주며)

To open it, use the metal handle.

열 때는 쇠 손잡이를 잡으세요.

Do I pull this?

이거 당겨요?

오늘의 단어pull당기다

팔을 벌려 크기를 보여 줄 때 써요.

What size box do you need? Give me a rough idea.

상자 크기 어느 정도 필요해요? 대충 알려 줘요.

It's this wide, like this!

이만큼 넓어요, 이렇게요!

오늘의 표현this wide이만큼 넓다(손 벌려 보이며)

The show starts soon! Please find a seat.

공연 곧 시작해요! 자리에 앉아 주세요.

This spot? Can I sit here?

이 자리요? 여기 앉아도 돼요?
