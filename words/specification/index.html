specification 뜻은 뭐예요?

레벨 L8 · 토플 95~113점 수준

specification = 사양(만들 때 지킬 자세한 조건) — 어떤 것을 만들 때 크기, 재료, 성능 같은 걸 어떻게 해야 하는지 자세히 정해 둔 조건

아이에게 specification를 어떻게 설명해요?

이렇게 읽어 주세요.

반티 맞출 때 업체에 보내는 주문서를 떠올려 봐.

색은 남색, 앞에는 반 이름, 글씨체, 천 두께, 사이즈별로 몇 장인지까지 다 적잖아.

이렇게 뭘 만들기 전에 '꼭 이대로 만들어'라고 정해 둔 자세한 조건이 specification이야. 폰, 건물, 기계에도 다 있어.

쓰는 법을 알려 주는 설명서나 대충 그린 그림하고는 달라. 만드는 쪽이 지켜야 하는 세부 목록이야.

specification는 어떤 상황에서 써요?

  • Every window in the new gym must match the specification, or the builders have to change it.

    새 체육관 창문은 전부 정해진 기준에 맞아야 하고, 안 맞으면 짓는 사람들이 고쳐야 해.

specification 문제, 아이와 같이 풀어 볼까요?

  1. 문제 1체육대회 우승 트로피를 공방에 맡기면서 이런 메모를 보냈어. '높이 30cm, 받침은 원목, 윗부분은 금색 금속 컵 모양, 받침 앞면에 3반 우승 글자 새김.' 이 메모가 'specification'이야?

    1. 응, specification 맞아
    2. 아니, specification 아니야

    정답 응, specification 맞아

    까닭 맞아! 트로피를 만들기 전에 높이 30cm, 원목 받침, 금색 금속 컵 모양, 3반 우승 글자까지 공방이 꼭 지켜야 할 조건을 하나하나 정해 보냈잖아. 그래서 이 메모가 바로 specification이야.

  2. 문제 2동아리방에 둘 책장을 목공소에 맡기면서 이런 문자를 보냈어. '보기 좋고 오래 쓸 수 있게 알아서 잘 만들어 주세요.' 이 문자가 'specification'이야?

    1. 응, specification 맞아
    2. 아니, specification 아니야

    정답 아니, specification 아니야

    까닭 맞아! 이 문자에는 책장 크기도, 나무 재료도, 칸이 몇 개인지도 하나도 안 적혀 있잖아. 알아서 잘 만들어 달라는 부탁일 뿐이고, 목공소가 꼭 이대로 만들어야 하는 조건 목록은 아니니까 specification이 아닌 거야.

  3. 문제 3학교에서 급식실 식탁을 새로 주문하면서 업체랑 종이를 여러 장 주고받았어. 이 중에서 'specification'이라고 부를 수 있는 건 뭘까?

    1. ①나사 A부터 끼우고 다리 B는 나중에 달라고 순서를 그려 놓은 종이
    2. ②튼튼하고 예쁘게, 너무 비싸지 않게만 해 달라고 부탁한 종이
    3. ③길이는 180cm, 다리는 철, 윗판은 흰색으로 하라고 적은 종이
    4. ④한 개에 15만 원, 열 개면 150만 원이라고 값을 적어 보낸 종이

    정답 ③ 길이는 180cm, 다리는 철, 윗판은 흰색으로 하라고 적은 종이

    까닭 맞아! 길이 180cm, 다리는 철, 윗판은 흰색처럼 식탁을 만들기 전에 이대로 만들라고 조건을 하나하나 정해 준 거라서, 바로 그게 specification이야.
