rapport 뜻은 뭐예요?

레벨 L8 · 토플 95~113점 수준

rapport = 친밀감 — 사람 사이에 서로 마음이 잘 맞고 편하게 통하는 느낌

아이에게 rapport를 어떻게 설명해요?

이렇게 읽어 주세요.

새로 온 과외 선생님이랑 처음엔 한마디 하는 것도 어색했지.

근데 몇 주 지나니까 질문도 편하게 하고, 농담도 서로 주고받게 됐어. 그렇게 생긴 편한 느낌이 rapport야.

꼭 친구 사이에서만 생기는 게 아니야. 의사와 환자 사이에도, 점원과 손님 사이에도 생겨.

한쪽만 상대를 좋아하는 인기랑도 다르고, 오래 쌓인 우정이랑도 달라. 양쪽이 서로 주고받으면서 생기는 거야.

rapport는 어떤 상황에서 써요?

  • The new nurse quickly built a good rapport with the old patients.

    새로 온 간호사는 할머니, 할아버지 환자들이랑 금방 잘 통하는 사이가 됐어.

rapport 문제, 아이와 같이 풀어 볼까요?

  1. 문제 1축구부에 새 코치님이 오셨어. 처음엔 서로 말을 아꼈는데, 몇 번 연습하고 나니 선수들이 작전에 대해 편하게 의견을 말하고 코치님과 농담도 주고받게 됐어. 코치님과 선수들 사이에 생긴 이 편하고 잘 통하는 느낌, 이게 'rapport'야?

    1. 응, rapport 맞아
    2. 아니, rapport 아니야

    정답 응, rapport 맞아

    까닭 맞아! 처음엔 서로 말을 아꼈는데, 몇 번 연습하고 나서 선수들이 작전 의견을 편하게 말하고 코치님과 농담도 주고받게 됐잖아. 이렇게 양쪽이 서로 주고받으면서 생긴 편하고 잘 통하는 느낌이 바로 rapport야.

  2. 문제 2과학 시간에 다른 반 아이와 같은 조가 돼서 3주째 실험 보고서를 같이 쓰고 있어. 그런데 아직도 말을 걸 때마다 어색하고, 대화가 자꾸 뚝뚝 끊겨. 이 두 사람 사이의 느낌, 이게 'rapport'야?

    1. 응, rapport 맞아
    2. 아니, rapport 아니야

    정답 아니, rapport 아니야

    까닭 잘 골랐어! 3주째 같이 보고서를 쓰는데도 말 걸 때마다 어색하고 대화가 뚝뚝 끊기잖아. rapport는 서로 편하게 통하는 느낌이니까, 이 두 사람 사이엔 아직 rapport가 없는 거야.

  3. 문제 3네 장면이 있어. 그중에서 'rapport'가 생겼다고 말하기에 가장 알맞은 건?

    1. ①처음 만난 상담 선생님과 몇 번 얘기하니 서로 편하고 잘 맞게 됐어
    2. ②반 아이들 모두가 전학생 이름을 알고 날마다 그 애 이야기를 했어
    3. ③학생들이 수업 시간마다 선생님을 무서워하며 조용히 앉아 있었어
    4. ④짝꿍과 같은 반이 된 지 한 달째인데 아직 서로 말이 거의 없어

    정답 ① 처음 만난 상담 선생님과 몇 번 얘기하니 서로 편하고 잘 맞게 됐어

    까닭 맞아! 처음 만난 상담 선생님이랑 몇 번 얘기하면서 서로 편하고 잘 맞게 됐잖아. 양쪽이 주고받으면서 생긴 그 편한 느낌이 바로 rapport야. 친구 사이가 아니어도 이렇게 생겨.
