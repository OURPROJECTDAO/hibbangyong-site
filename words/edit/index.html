edit 뜻은 뭐예요?

레벨 L2 · 중학교~고1 공통영어 · 조금 더 넓은 말

edit = 편집하다 — 이미 다 만들어 놓은 글이나 영상을 다시 손봐서 빼거나 넣거나 바꾸는 것.

아이에게 edit를 어떻게 설명해요?

이렇게 읽어 주세요.

내가 찍은 영상을 다시 틀어 봤어. 앞부분이 너무 길더라. 그래서 거기를 싹둑 잘라내고 뒷부분 순서도 바꿨어.

틀린 데를 바로잡을 때만 쓰는 말이 아니야. 아무 문제 없이 멀쩡한 부분도 빼거나 바꿀 수 있거든?

쓴 글도 똑같아. 문장 하나 지우고 다른 말로 갈아끼우는 거.

없던 걸 새로 만드는 게 아니라 다 만들어 놓은 걸 다시 손보는 거, 그게 edit야.

edit는 어떤 상황에서 써요?

  • My sister edited the photo and made my hat blue.

    언니가 사진을 편집해서 내 모자를 파란색으로 바꿨어.

edit 문제, 아이와 같이 풀어 볼까요?

  1. 문제 1형이 어제 만든 만화책 대사 칸을 다시 펴서, 세 번째 칸 대사를 지우고 대신 다른 대사를 적어 넣었어. 이게 'edit'이야?

    1. 응, edit 맞아
    2. 아니, edit 아니야

    정답 응, edit 맞아

    까닭 맞아! 이미 다 만들어 놓은 만화책을 다시 펴서 대사를 지우고 다른 걸 적어 넣었잖아. 새로 그린 게 아니라 있던 걸 손본 거니까 바로 그게 edit인 거야.

  2. 문제 2동생이 아무것도 안 그려진 새 도화지를 꺼내서, 머릿속에 떠오른 로봇을 처음부터 그리기 시작했어. 이게 'edit'이야?

    1. 응, edit 맞아
    2. 아니, edit 아니야

    정답 아니, edit 아니야

    까닭 맞아! 아무것도 없는 새 도화지에 처음부터 그리는 건 없던 걸 새로 만드는 거잖아. edit은 이미 다 만들어 놓은 걸 다시 손보는 거라서, 이건 edit이 아닌 게 맞아.

  3. 문제 3친구 네 명이 방금 자기가 한 일을 말했어. 이 중에서 'edit'을 한 사람은 누구야?

    1. ①빈 종이에 아무것도 없던 이야기를 처음부터 새로 지어낸 아이
    2. ②다 쓴 일기를 처음부터 끝까지 소리 내어 한 번 읽어 본 아이
    3. ③다 쓴 일기에서 한 문단을 빼고 다른 문장을 대신 넣은 아이
    4. ④칠판에 적힌 문장을 자기 공책에 그대로 똑같이 옮겨 적은 아이

    정답 ③ 다 쓴 일기에서 한 문단을 빼고 다른 문장을 대신 넣은 아이

    까닭 맞아! 다 써 놓은 일기에서 문단을 빼고 다른 문장을 대신 넣었잖아. 이미 있던 글이 진짜로 달라진 거지. 바로 그게 edit이야.
