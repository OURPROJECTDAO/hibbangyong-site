pull 뜻은 뭐예요?

레벨 L1 · 중학교~고1 공통영어 · 눈에 보이는 말

pull = 당기다 — 잡고 내 쪽으로 오게 힘 주다(끌다)

아이에게 pull를 어떻게 설명해요?

이렇게 읽어 주세요.

줄 끝을 잡아봐. 그리고 나 있는 쪽으로 힘을 줘. 그럼 줄이 스르륵 딸려와.

서랍도 문도 그래. 잡고 내 쪽으로 오게 하면 다 이거야.

수레 손잡이를 잡고 걸어가도 그래. 수레가 내 뒤를 졸졸 따라오거든?

미는 거랑은 반대야. 미는 건 저쪽으로 가버리고, 이건 내 쪽으로 와. 그게 pull이야.

pull는 어떤 상황에서 써요?

  • I had to pull the wagon up the hill.

    나는 언덕 위로 수레를 끌고 올라가야 했어.

pull 문제 하나, 아이와 같이 풀어 볼까요?

  1. 문제 1강아지 목줄 끝을 잡고 내 쪽으로 힘을 줬더니 강아지가 내 앞으로 딸려왔어. 이게 'pull'이야?

    1. 응, pull 맞아
    2. 아니, pull 아니야

    정답 응, pull 맞아

    까닭 맞아! 줄 끝을 잡고 네 쪽으로 힘을 줬더니 강아지가 네 앞으로 딸려온 거잖아. 잡고 내 쪽으로 오게 하는 것, 그게 바로 pull인 거야.
