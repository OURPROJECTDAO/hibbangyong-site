compatible 뜻은 뭐예요?

레벨 L6 · 뉴스·드라마에 자주 나오는 말 · 생각을 나타내는 말

compatible = 서로 잘 맞는 — 달라도 같이 쓰면 문제없이 잘 돌아가는

compatible, 쉽게 풀면 어떤 말이에요?

새 게임기를 샀는데, 옛날 충전기를 꽂으니까 딱 맞물려서 충전이 되네? 서로 맞는 거야.

근데 똑같이 생겨야 맞는 게 아니야. 모양이 달라도 같이 잘 돌아가면 맞는 거거든.

사람도 그래. 성격이 서로 달라도 같이 있을 때 안 부딪히고 편하면, 둘이 잘 맞는 거야.

이렇게 서로 부딪히지 않고 같이 잘 되는 게 compatible이야.

compatible는 어떤 상황에서 써요?

  • My old charger is compatible with my new phone, so it still works.

    내 옛날 충전기가 새 폰이랑 잘 맞아서, 아직도 충전이 돼.

compatible 문제 하나, 풀어 볼까요?

  1. 문제 1물건들이 서로 어떤 사이인지 말했어. 이 중에서 두 개가 서로 'compatible'한 건 어떤 거야?

    1. ①옛날 충전기랑 새 폰은 생긴 건 서로 다른데, 같이 쓰니까 문제없이 충전이 잘 돼.
    2. ②빨간 모자랑 빨간 신발은 색이 똑같아서 같이 하면 세트처럼 잘 어울려 보여.
    3. ③이 우산은 비 오는 날 혼자 쓰기에 딱 알맞은 크기야.
    4. ④새 헤드폰을 폰에 꽂으면 소리가 자꾸 끊겨서 같이 못 써.

    정답 ① 옛날 충전기랑 새 폰은 생긴 건 서로 다른데, 같이 쓰니까 문제없이 충전이 잘 돼.

    까닭 맞아! 옛날 충전기랑 새 폰은 생긴 건 다른데도 같이 꽂으니까 문제없이 충전이 되잖아. 서로 달라도 부딪히지 않고 같이 잘 돌아가니까, 바로 그게 compatible인 거야.
