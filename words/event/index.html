event 뜻은 뭐예요?

레벨 L2 · 중학교~고1 공통영어 · 조금 더 넓은 말

event = 일 — 딱 벌어진(일어난) 하나의 일. (생일 파티 같은 행사도, 갑자기 난 사고도 다 event)

아이에게 event를 어떻게 설명해요?

이렇게 읽어 주세요.

달력에 동그라미 친 날 있지? 그날 뭔 일이 딱 벌어져.

생일 파티일 수도, 학교 운동회일 수도 있어.

좋은 일이든 갑자기 난 사고든, '벌어진 하나의 일'이면 다 event야.

손에 쥐는 물건이 아니라 '일어난 일'인 거 — 그게 event야.

    정답 아니, event 아니야
