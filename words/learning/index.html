    2. 아니, learning 아니야

    정답 응, learning 맞아

    까닭 맞아! 동생이 처음엔 매듭이 자꾸 풀렸는데, 여러 번 해 보더니 이제는 혼자서 리본 모양으로 꽉 묶잖아. 못 하던 걸 할 수 있게 됐으니까 바로 그게 learning인 거야.

  2. 문제 2형은 작년에 피아노 곡 하나를 처음부터 끝까지 칠 수 있었어. 그런데 1년 동안 한 번도 안 쳤더니 이제는 첫 줄밖에 기억이 안 나. 이게 'learning'일까?

    1. 응, learning 맞아
    2. 아니, learning 아니야

    정답 아니, learning 아니야

    까닭 맞아! 형은 전에 칠 수 있던 피아노 곡을 1년 동안 안 쳐서 이제 첫 줄밖에 기억이 안 나잖아. 할 수 있던 게 거꾸로 빠져나간 거라서 learning이 아닌 거야.

  3. 문제 3네 사람에게 이번 주에 일어난 일이야. 'learning'이 일어난 사람은 누구일까?

    1. ①형이 책상 앞에 한 시간 앉아 있었는데 책장은 한 장도 안 넘겼어.
    2. ②할머니가 옛날부터 잘 아는 노래를 오늘도 흥얼거리셨어.
    3. ③동생이 숟가락질을 몇 번 흘리더니 이제 혼자서 잘 떠먹어.
    4. ④누나가 지난주에 외운 구구단 7단을 오늘 다 까먹었어.

    정답 ③ 동생이 숟가락질을 몇 번 흘리더니 이제 혼자서 잘 떠먹어.

    까닭 맞아! 동생이 처음엔 숟가락질하다 몇 번 흘렸는데, 이제는 혼자서 잘 떠먹잖아. 못 하던 걸 흘리면서도 해 보다가 할 수 있게 된 거, 바로 그게 learning이야.
