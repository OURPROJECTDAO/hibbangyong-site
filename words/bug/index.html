    1. 응, 맞아
    2. 아니, 아니야

    정답 응, 맞아

  2. 문제 2bug은 어느 것일까?

    1. ①하늘 높이 떠서 밝게 빛을 내는 아주 큰 것
    2. ②땅이나 잎 위를 여러 개의 다리로 기어다니는 작은 것
    3. ③물속에서 지느러미로 이리저리 헤엄쳐 다니는 것
    4. ④길 위를 둥근 바퀴로 빠르게 굴러다니는 것

    정답 ② 땅이나 잎 위를 여러 개의 다리로 기어다니는 작은 것
